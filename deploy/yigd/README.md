# MoveEarth v3.8 — YIGD切り替え用ファイル

Minecraft 1.21.1 / NeoForge。採用版はYIGD 2.0.13を基にメタデータを修正した `2.0.13.1-moveearth`。
Cloth Config 15.0.140 NeoForgeが必要（既に同版があれば追加しない）。YIGD・Cloth Configは両側に必要。
MoveEarthの基礎プロトコルは3.7のままだが、今回のModpack更新ではYIGDと対応するMoveEarth v3.8を両側へ導入する。
本ディレクトリは導入用プロファイルであり、本番へは自動適用しない。

## 動作と理由

- 死亡品を墓で保管し、クリック回収で元の装備・スロット配置を優先する。散乱による回収の不便を抑える。
- PlayerReviveの瀕死状態は生存扱いのまま。最終死亡でYIGDが墓を作る。PlayerReviveはHIGHESTで死亡を取り消し、YIGDはLOWESTで確定死亡を扱うことを実物jarで確認した。実ゲームでの最終確認は下記の通り必要。
- 所属国は死亡時に保存。自国領土内の墓は国民、物資利用権限がある同盟国、当該国への略奪権がある攻撃側、および運営だけが回収できる。本人は離国後も回収できる。
- 死亡時点で自国領土外なら即座に公開。無所属の死亡も公開。
- 保護中の墓が自国領土外の別位置へ配置されると永久に開錠。戻しても再施錠しない。所属国・開錠・最後の配置場所は再起動後も維持する。同じ場所でのチャンク再読込や領土の変化だけでは開錠しない。
- YIGDの配置・移動検出に連携するだけで、担送・墓の持ち運び機能は追加しない。PlayerReviveにも死亡後の墓の担送機能はない。
- 未追跡の既存YIGD墓は現在の国籍から所有国を推測せず、本人と運営による回収に限定する。
- 魂縛、墓探知エンチャント、鍵、巻物、遠隔回収、テレポート、ランダム敵出現、追加の死亡デバフ、ランダムアイテム消失を無効にする。墓と回収のQoLに絞り、戦争ルールへの影響を避ける。
- 既定の「他人の墓を1時間後に回収可能」を無効にし、MoveEarthの領土判定を回収イベントの権威とする。墓自体のロックフラグや鍵では領土保護を迂回できない。
- 一般プレイヤーのリモート復元・開錠操作を許可しない。管理用コマンドの既定権限は2以上。

## 切り替え手順

1. ワールド、プレイヤーデータ、設定、旧MOD一式のバックアップを取る。
2. **旧Corpseが動いている間に、残っている死体の物資を回収・返却する。** Corpseの死体・履歴をYIGDへ自動変換する機能はない。中身が残ったままCorpseを外すと回収できなくなる。未回収がある場合は切り替えを保留し、運営による回収を先に行う。
3. サーバーを正常停止する。稼働中にjarを入れ替えない。
4. 両側で `corpse` と `corpsecurioscompat` を外す。旧jarと元ワールドはバックアップに残す。CorpseとYIGDを同時に死亡処理させない（重複・欠落の可能性がある）。MoveEarthは両方が入った構成の起動を拒否する。
5. 独自MODは `build/libs/moveearth_addtional-3.8.0-server.jar` をサーバーへ、`build/libs/moveearth_addtional-3.8.0-player.jar` をクライアント配布物へ反映する。ModpackへのマージとYIGD・Cloth Configの用意は運用側で行う。同一MODの旧jarは外し、二重に置かない。既存Cloth Config同版はそのままでよい。
6. `config/yigd.json` を配布する。既にYIGD設定がある場合はバックアップの上で差分を確認する。他の設定ファイルを削除しない。
7. まずバックアップの複製を使った検証環境で、下記チェックを行ってから本番に適用する。

## 導入時のゲーム内確認

- 瀕死 → 蘇生では墓ができず、装備も消えない。最終死亡では墓が1個だけできる。
- メイン・装備・オフハンド・Curios・バックパックの中身を回収でき、複製や欠落がない。
- 自国領土内では本人・国民・権限付き同盟国が回収でき、敵国・中立・無所属は回収できない。
- 略奪権の対象国・場所・有効期間に従って回収が制限される。
- 荒野・他国領土での死亡品は無所属の人でもすぐ回収できる。
- 移動手段を別途用意する場合のみ、墓の移設時にYIGDの墓IDが保たれ、領土外で開錠し、戻しても公開のままであることを確認する。
- 再起動・チャンク再読込・離国後にも所有権と回収可否が正しい。
- 鍵・巻物・遠隔復元等で領土保護を迂回できない。

## 配布jarの修正とライセンス

元ファイルは `upstream.json` にURL・Modrinth版ID・SHA512を固定した。
元jarのMinecraft依存範囲 `[1.21,1.21.1)` は1.21.1を除外するため、採用版では `[1.21.1,1.21.2)` に修正した。
変更の識別のためMOD版を `2.0.13.1-moveearth` に変更し、MITライセンスと変更通知をjar内に追加する。
それ以外の元jarエントリ（全ゲームクラス・リソース）はバイト一致を確認する。
YIGDはMIT。著作権・許諾表示を `licenses/YIGD-MIT.txt` とjar内に同梱する。

今回のリリースでは独自MODのサーバー・クライアントjarのみを渡し、ZIPや第三者MODの配布セットは生成しない。既存の `build/releases/` は最新のMoveEarth jarとは限らないため、独自MODの取得元には使わない。

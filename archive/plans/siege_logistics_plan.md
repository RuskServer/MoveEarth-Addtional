# Siege・略奪・兵站実装計画

更新: 2026-09-19

## 第一段階：戦争判定と輸送の土台（実装済み）

- 正規防衛メンバー不在では反攻ゲージ減衰。防衛傭兵だけでの進捗保持を廃止。
- ダウン・拘束・収監中のプレイヤーを反攻と妨害の人数から除外。
- Siege受付時の補強最大HP・個数上限を保存し、復興は同じ個数内の実HPで評価。
- 最終陥落時の残存数を基準にして壊滅したほど復興が容易になる問題を、新規戦争で解消。
- 評価個数は開戦時に固定（設定上限4,096）。丸石の大量設置で素材差を回避しない。
- NBTへ基準・評価方式を保存。既存エピソードは素材履歴がないため旧個数評価を維持。
- Bastionの降車禁止・強制帰還を解除。旧帰還予約はログイン時に消去。
- 既存の設置・パール制限、C4例外、露出コアへの工作条件は維持。
- 自国車両に接続した収納は領土外で使用・設置可能。領土の代わりに車両所有国を検証。

## 第二段階：略奪権（実装済み）

収納設置権限と収納内容の回収権限を分離し、下記の共通判定を通常収納・残骸へ適用する。

| 戦況 | 敵の回収権 |
| --- | --- |
| 通常・初動・ローリング・陥落後20分未満 | なし |
| 陥落後20～30分 | コア中心以外。正規攻撃勢力のみ |
| 陥落確定後 | 元の領域全体。ただし金庫を除く。期限付き |
| 金庫 | 敵の回収を拒否 |

- 最終陥落時に旧領域・旧所有国・Siege ID・攻撃勢力を保存。現在の領土判定だけに依存しない。
- 陥落確定後30開放分（設定可能）の略奪猶予を付与。
- 単独Siegeは本人のみに付与。第三国・無関係な傭兵は便乗できない。
- 講和・反攻成功で対応する略奪権を失効。GUIを開きっぱなしでも回収できない。
- 所有国の引出しまで一律凍結しない。金庫指定の戦闘中変更禁止を維持。
- 金庫は1チャンク保護を初期仕様とし、容量上限は別途バランス調整項目。
- 直接GUI、ブロック破壊、ホッパー、Createのアーム・漏斗・シュートへ同じ境界を適用。
- 自動搬出には操作プレイヤーがいないため、戦時搬出の所有境界ルールを明示し、敵の機械から抜けないことを保証する。

## 第三段階：収納残骸（実装済み）

- 爆破で対象収納が失われるとき、中身を散乱させず現地の回収対象として保存。
- 正規回収元を一つに固定し、元収納と残骸に同じアイテムを同時保持しない。
- `nation_storage_blocks`内の標準Containerを対象化。安全に読めないMOD収納は爆破せず保護して警告。
- ダブルチェストは片側単位のデータと結合GUIを区別。未開封LootTableも保持。
- 再爆破・回収中断・チャンク再読込・サーバー再起動でも消失・複製しない。
- 他MODに安全な保存APIがない場合、変換せず保護を維持する。未対応を黙って通常爆破へ通さない。
- CBCの直撃・地形変換、通常Explosion、Warnautics独自の爆破経路を全て確認。
- 金庫収納は残骸化後も敵が取得できない。残骸移送・ピストン・Sable組立で権限を失わない。
- 破壊者UUID、発射時所属、Siege、旧所有国、座標、生成・回収時刻を記録。
- GriefLoggerとは独立したMoveEarth戦史へ生成を記録。外部ロールバックとの同時運用は実機検証項目として残す。

## 第四段階：輸送対象・撃破記録（実装済み）

- コアHPが正から0へ移る瞬間に、車両ID・所有国・加害者・兵器を一度だけ記録。
- 撃破車両の貨物にも期限付き回収権を付与。車両修理で即時に取り消すかは領土略奪権と区別する。
- 捕虜は徒歩係留・騎乗禁止を維持。拘束具を持って自国車両コアをスニーク右クリックする専用操作で積み降ろし。
- 車両IDへ拘束先を移し、護送者・車両の消失や撃破時の救出、チャンク未ロード、再起動を処理。
- 乗せ替えや護送者交代で3開放時間の拘束期限を延長しない。
- 検知設備の侵入警告は追加候補。降下しただけで工作を禁止する特殊状態は作らない。

## 検証

単体テストは、反攻増加・停止・減衰、安価ブロックの大量追加、未修理HP、
基準の上書き拒否・復元・終了後破棄を対象とする。
実機では以下を確認する。

1. 防衛傭兵のみ／正規兵のみ／両軍／ダウン兵／拘束兵を12ブロック圏へ配置。
2. ダイヤ補強を開戦後に全破壊し、再起動後も目標HPと個数が維持されること。
3. 復興前から存在したエピソードが旧評価のまま表示・完了できること。
4. 開放時間・維持費・停戦・反攻による他の保護が変わっていないこと。
5. 敵領土で降車し、再ログインしても旧Bastion帰還が発動しないこと。
6. 自国車両、他国車両、スイベル・ヒンジ接続、切り離された部品で収納権限を確認。
7. 陥落0～20分、20～30分、確定後、期限切れ、金庫、単独Siege、第三国で収納権限を確認。
8. チェスト・樽・シュルカーを通常爆発、CBC、Warnauticsで壊し、再起動と再爆破後も一意に回収できること。
9. 車両HPが0になった一度だけ戦史へ記録され、貨物権が攻撃勢力だけへ付くこと。
10. 捕虜積載、再起動、降車、護送者離脱、車両撃破救出でも3開放時間が延長されないこと。

重砲の射撃準備時間は引き続き実装しない。固定砲・車載砲の優位性は実戦データで判断する。

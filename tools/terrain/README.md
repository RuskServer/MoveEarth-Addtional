# 地形生成ツール (Phase 1)

[terrain_generation_plan.md](../../terrain_generation_plan.md) のPhase 1。
オフラインで地形をシミュレーションし、**タイル資産**と**検証用PNG**を出力する。

ゲーム側には何も触れない。Phase 1はPNGだけで品質を判断し、
納得できなければここで中止してMOD側の実装に入らない。

## 実行

```shell
python3 tools/terrain/generate.py --size 1024 --out build/terrain/tile_0_0
```

依存はnumpyとPillowのみ。scipyもnumbaも使わない。

河川修正版は `river_segments.json` を出力する。`tile.json`と各binに加え、このファイルも
サーバーへ配置する。新形式では河道を線分から評価するため、粗い距離場の双線形補間に
よる斜め水路の欠損を避けられる。既存の生成済みチャンクには反映されない。
品質確認は新規ワールドで行い、利用中のタイルを直接上書きしないこと。

河川の回帰テスト: `python3 -m unittest discover -s tools/terrain -p 'test_*.py'`

主なオプション:

| オプション | 内容 |
|---|---|
| `--size N` | グリッド解像度（セル数） |
| `--blocks-per-cell N` | 1セルが覆うワールドブロック数 |
| `--seed N` | 乱数シード |
| `--erosion-steps N` | 侵食の反復数 |
| `--origin X Z` | タイル原点のワールド座標 |
| `--set KEY=VALUE` | `Config`の任意の項目を上書き（複数可） |

`--set`で上書きできる項目は [`terraingen/config.py`](terraingen/config.py) を参照。

## 処理の流れ

| 段階 | モジュール | 内容 |
|---|---|---|
| プレートと隆起 | `tectonics.py` | ドメインワープしたボロノイでプレート分割、境界の収束量から隆起場を作る |
| 侵食 | `erosion.py` | 隆起・stream power則による下刻・熱侵食を交互に反復 |
| 水文 | `hydro.py` | 窪地埋め（Planchon-Darboux）、D8流向、流量集積 |
| 高度分布 | `hypsometry.py` | 陸と海を地球の高度分布曲線へランク写像（単調なので水系は不変） |
| 気候 | `climate.py` | 緯度勾配、帯状の降水供給、卓越風に沿った移流による地形性降水 |
| 地方 | `regions.py` | 大陸の連結成分、流域、目標面積までの併合 |
| 出力 | `render.py` / `tiles.py` | PNGとタイル資産 |

## 設計上の要点

**線状の山脈はプレート境界から作る。** 等方的なノイズからは造山帯が出ない。
地図が地球に見えるかどうかはここで決まる。

**プレート割り当てにドメインワープをかける。** かけないとボロノイの多角形が
海岸線としてそのまま見えてしまい、最も人工的に見える原因になる。

**海面はノイズ振幅の調整ではなく分位点で決める。** `land_fraction`が
そのまま陸海比になるので、要件を構成的に満たせる。

**流量集積はbincountの不動点反復で解く。** numbaが無い環境でもベクトル化が保てる。
連結成分と流域の根探索はポインタジャンプで、どちらもセル単位のPythonループを避ける。

**流向計算には固定の微小ジッタを足す。** 平坦な海岸平野ではD8のタイブレークが
常に同じ向きに解決され、河川が格子軸に沿った平行な直線になる。
**ジッタは窪地埋めの前に入れる。** 後に足すと埋め立てのepsilon勾配より桁違いに大きく、
埋めたはずの窪地を掘り直して河川が内陸に取り残される。

**低地・丘陵・山地の配分は隆起の調整ではなく高度分布の写像で決める。** 隆起を強めれば
一様な台地に、弱めれば一様な平原になり、パラメータの押し合いでは決まらない。
大陸棚と大陸斜面も、地殻の段差をぼかすのではなくこの写像が直接作る。

## 出力

```
<out>/
├─ relief.png            陰影起伏＋河川  ← 主要な判断材料
├─ relief_norivers.png
├─ continents.png        大陸分割
├─ regions.png           地方分割（流域由来）
├─ plates.png            プレート（デバッグ用）
├─ temperature.png
├─ humidity.png          雨陰の確認
├─ flow.png              流量集積
├─ height.bin ほか       タイル資産（各レイヤー）
├─ tile.json             タイル記述子＋指標
└─ config.json           使用したパラメータ
```

## 完了条件の指標

実行終了時に出る数値が計画書Phase 1の完了条件に対応する。

| 指標 | 意味 | 目安 |
|---|---|---|
| `land_fraction` | 陸海比 | 0.30（構成的に満たす） |
| `ridge_elongation` | 高地の細長さ。1.0は等方的な塊 | 2.0以上 |
| `shelf_share_of_ocean` | 大陸棚が海に占める割合 | 0.07〜0.15（地球は約7.5%） |
| `river_reaches_sea` | 海へ到達する河川セルの割合 | 1.0 |
| `rain_shadow_ratio` | 風下／風上の湿度比。低いほど雨陰が強い | 0.2〜0.5 |
| `largest_continent_span_blocks` | 最大大陸の差し渡し | 徒歩横断が過大にならない範囲 |
| `regions` | 地方数 | 資源プロファイル数と釣り合う範囲 |

## 注意

出力タイルは**サーバー側にのみ配置する**。worldgenはサーバーで完結するため、
公開するクライアントjarへは含めない。
